## [0.2.0] - 2026-11-09

### 🚀 Features

- *(core)* Domain types, slot markers and RFC 7807 errors
- *(templates)* Embed the compiled badge catalog and shared keyframes
- *(theme)* Semantic color system with contrast and mix presets
- *(render)* Takumi render pipeline with bundled fonts
- *(icons)* Simple Icons catalog, SVG sanitizer and upload store
- *(data)* Live badge data services with SSRF guard
- *(cache)* Two-tier render cache with structural ETags
- *(auth)* API keys, sessions, tiers and GitHub OAuth
- *(billing)* Stripe webhook verification and subscription state
- *(api)* Badge routes, auth wall, account keys and webhooks
- *(server)* Add the vexillum-server origin binary
- *(worker)* Add the Cloudflare edge worker for static badges
- *(web)* Scaffold the Vite + React + Tailwind SPA
- *(web)* Add UI primitives and the shared app chrome
- *(web)* Add badge-preview primitives and theme helpers
- *(web)* Add the landing and explore pages
- *(web)* Add the playground editor
- *(web)* Add the docs and auth pages

- *(badges)* Badge catalog with shared palettes and variants
- *(compiler)* Build the badge compiler and its outputs
- *(converter)* Expand the token converter surface
